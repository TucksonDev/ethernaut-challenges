****************
* PuzzleWallet *
****************

- The storage slots from the proxy and the ones from the implementation collide, so the slots 0 and 1 refer to the same state variables in both contracts.
- You can then go through the proxy and implementation functions to escalate privileges:
    + proposeNewAdmin
    + addToWhitelist
    + multicall(), sending 0.001 ETH (the current balance of the contract) and 2 calls:
        1. deposit()
        2. multicall() with deposit() -- this will bypass the "depositCalled" filter
    + execute() to empty the contract balance
    + setMaxBalance(), passing the uint256 representation of the address to be admin
